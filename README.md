# AU Encounter Record FHIR Implementation Guide

The goal of [AU Encounter Record](http://build.fhir.org/ig/hl7au/au-fhir-encounter/) is to specify how to represent and exchange encounter information in HL7 FHIR within the Australian healthcare context, supporting consumers and their healthcare providers with timely access to relevant encounter specific information to enable effective coordination and continuity of care.

## Did you find an error?
If it's a specification error please search the issues list in [GitHub](https://github.com/hl7au/au-fhir-encounter/issues) to ensure the error was not already reported. If the error hasn't been reported you can use [create a new issue](https://github.com/hl7au/au-fhir-encounter/issues/new).

## Contributing to Development

AU Encounter Record R1 is in currently in development.

### 1. Join the AU Encounter Record FHIR IG Calls

See [Register for Sparked](https://sparked.csiro.au/index.php/registration-form/) for information on how to participate in AU Encounter Record FHIR IG call, the AU Core Work Group, and Clinical Design Group as part of [Sparked](https://sparked.csiro.au/), the Australian FHIR Accelerator. 

Visit the [AU Encounter Record FHIR IG Project page](https://confluence.hl7.org/spaces/HAAUCOREWG/pages/482411407/AU+Encounter+Record+FHIR+IG+Project) and the [HL7 Australia - AU Core Work Group Home](https://confluence.hl7.org/spaces/HAAUCOREWG/pages/184913442/HL7+Australia+-+AU+Core+Work+Group+Home).

### 2. Discuss an issue in chat.fhir.org

If you have a question, feature request, or proposed change, the best place to start is Zulip e.g. the https://chat.fhir.org/#narrow/stream/179166-implementers stream. If what you want to discuss is specific to Australia you can post in the Australia stream https://chat.fhir.org/#narrow/stream/179173-australia in the [AU Encounter Record topic](https://chat.fhir.org/#narrow/channel/179173-australia/topic/AU.20Encounter.20Record).

### 3. Identify future work or raise discussion points

To identify future work or raise discussion points, you can post in the Australia stream https://chat.fhir.org/#narrow/stream/179173-australia or raise [specification feedback](https://confluence.hl7.org/display/HL7/Specification+Feedback) through a [Jira issue tracker](https://jira.hl7.org/issues/?filter=21325).

### 4. Discuss with the team

Once the issue is logged, you should discuss with the team on [chat.fhir.org in the australia > AU Encounter Record topic](https://chat.fhir.org/#narrow/channel/179173-australia/topic/AU.20Encounter.20Record) before attempting to make changes yourself. It's important to coordinate with the other people working on the project.

### 5. Create a pull request

When everyone has agreed on a course of action, IG changes should be submitted as a pull request for review in this repository.
